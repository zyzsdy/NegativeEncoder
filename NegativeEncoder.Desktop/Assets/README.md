# Desktop app icon

`app-icon.png` is the 1024 × 1024 RGBA source for the new desktop app. The legacy
Windows icon remains in `NegativeEncoder/Resources/icon.png` as the brand reference.
The new icon was generated using the built-in ImageGen tool, then resized and
packaged with macOS `sips` / `iconutil`. The ICO contains PNG images at 16, 32, 128
and 256 pixels. The ICNS contains the standard 16–512 point sizes at 1× and 2×.

Generation prompt:

Use case: style-transfer. Asset type: macOS application icon for NegativeEncoder. Input image is the existing brand reference: a plump pink fish with lime-yellow triangular markings and a forked tail, pointed snout and simple eye. Redesign this same recognizable pink fish as a polished flat vector-style macOS app icon, bold simplified silhouette, crisp solid shapes, restrained magenta and pink tones and the existing yellow-green accents, no 3D rendering, no shiny material, no text. Retain the reference fish's diagonal pose, tail at upper left and head at lower right, round body and expressive eye. Center the fish large on a warm off-white rounded-square macOS tile with generous safe margins. Outside the rounded tile is genuinely transparent. Square 1024x1024 image, clean edges and legible at 32px. No additional symbols, no lettering, no mockup, no perspective tilt of the tile.
